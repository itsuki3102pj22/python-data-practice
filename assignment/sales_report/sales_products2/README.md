# SQLite・pandas 売上データ処理の学習

`database.py` では、売上データの登録、集計、整形、照合を個別の関数で練習します。店舗別レポートを扱う `main.py` の使い方は[リポジトリのREADME](../../../README.md#店舗別売上の分析照合)を参照してください。

## サンプルの店舗別照合

pandasをインストールした環境で、リポジトリのルートから実行します。

```sh
python assignment/sales_report/sales_products2/database.py
```

```text
店舗別整合性チェック：NG
名古屋店:売上データなし
福岡店:基準データなし
東京店: 売上データの金額が欠損
```

通常実行ではコード内のサンプルを照合します。入力には、店舗ごとに1行の `店舗名`・`売上金額` を持つ基準と集計結果のDataFrameを使います。

- 基準と集計結果を店舗名で外部結合し、`indicator=True` で基準側だけ、集計結果側だけ、両方にある店舗を判定します。
- 両方に店舗行があれば、金額の欠損を基準側、集計結果側、両側に分けて表示します。金額が揃っていれば「集計結果 − 基準売上」を求め、差額のある店舗を表示します。
- 問題のある店舗がなければ `OK` を表示します。結合キーの重複検証は未実装です。

## 関数で試せる処理

- `read_csv` と `list_read_csv` で売上CSVを結合し、SQLiteへの登録用に行をリストへ変換します。
- `create_sales` は日付・店舗名・商品名を複合キーとするテーブルを作ります。`insert_sales` は重複をスキップし、`upsert_sales` は同じキーの単価と販売数を更新します。
- SQLで店舗別・商品別・店舗×商品別の集計、`WHERE` と `HAVING` による絞り込みを行い、全店舗と店舗別の売上から構成比を計算できます。`sql_to_dataframe` は店舗別売上を `output/store_revenue.csv` に保存します。
- pandasで店舗名の半角・全角スペースを除去して結合し、重複削除前後の売上差額や、店舗・日付での集計前後の合計を確認します。店舗・日付をキーとする重複削除の例では先頭行を残します。
