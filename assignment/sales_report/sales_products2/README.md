# SQLite・pandas 売上データ処理の学習

`database.py` は、既存の `main.py` による売上レポート生成とは独立した学習用コードです。

## 学習した内容

- SQLite：CSV取り込み、テーブル作成、複合キーによる重複スキップ、UPSERTによる追加・更新。
- SQL：店舗別・商品別・店舗×商品別の売上集計、WHEREとHAVING、売上構成比。
- pandas：SQL結果のDataFrame化・CSV出力、mergeによる結合、店舗名の半角・全角スペース除去。
- 重複処理：drop_duplicates、店舗名・日付をキーにした重複確認と削除、削除前後の売上差額確認。
- 整合性チェック：groupby前後の合計比較、outer結合による店舗別の差額・欠損確認。

店舗別の差額は「集計結果 − 基準売上」です。合計が同じでも店舗間の過大・過小計上が相殺されるため、店舗単位で照合します。欠損は0円に補完せず、「基準データなし」「売上データなし」として表示します。

## 実行方法

pandasをインストールしたPython環境で、リポジトリのルートから実行します。

```sh
python assignment/sales_report/sales_products2/database.py
```

既定の実行はサンプルデータの店舗別整合性チェックのみです。福岡店について「基準データなし」と表示します。DBへの接続・書き込みは行いません。CSV取り込みやSQL集計は、各関数を明示的に呼び出す学習用の構成です。

## 判断と今後の課題

- 基準にない店舗は根拠を確認してから集計対象にする方針です。自動除外は未実装です。

- 現在の照合は店舗ごとに1行で金額が入力済みのデータを想定しています。行の不在と金額自体の欠損の区別、結合キー重複の検証は今後の課題です。
