# Python Data Practice

バックエンド開発の経験を活かしつつ、データ分析スキルや業務効率化・自動化の幅を広げるために作成した、Pythonによるデータ収集から分析・可視化までの実践学習リポジトリです。

## 🎯 リポジトリの目的
単なるデータ収集（スクレイピング）にとどまらず、取得したデータを加工・集計し、最終的にグラフ化してインサイトを得るまでの「一連のデータ分析パイプライン」**をハンズオン形式で習得することを目指しています。

🚀 現在の取り組み：Webスクレイピング学習
練習用ECサイト「Books to Scrape」を対象に、Pythonを用いたデータ収集の基礎を実装しています。

■ 実装ハイライト
単一・複数ページ対応のスクレイピング： Requests と BeautifulSoup4 を用いて、書籍タイトル・価格・評価などの商品情報を自動収集。

堅牢なデータ処理： 例外処理（タイムアウトやステータスコード検知）を実装し、安定したデータ取得を担保。

データ出力： 収集データを構造化し、CSVファイルとしてクリーンに出力。

■ 使用技術（現段階）
Python

Requests

BeautifulSoup4

urllib

CSV
